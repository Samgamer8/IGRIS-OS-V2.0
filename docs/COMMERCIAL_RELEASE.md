# Preparación comercial

La release técnica y la autorización legal son controles separados.

Antes de vender, copia `release/SELLER.example.json` como `release/SELLER.json`
y completa nombre legal, correo de soporte y jurisdicción. Un profesional debe
revisar licencia/EULA, privacidad, impuestos, marcas, garantías y normativa de
consumo aplicable. IGRIS no inventa esos datos ni declara asesoramiento legal.

No distribuyas `runtime/`, `.coverage`, logs de build, claves, bases de datos ni
staging de pruebas. Firma el ejecutable con un certificado del vendedor cuando
la identidad comercial esté disponible.
